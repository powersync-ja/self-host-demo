# Key Generator

This project creates a RSA key pair for signing JWTs in the PowerSync self hosted demo project.

# Installation

Install NPM dependencies

```bash
npm install
```

# Generating Keys

A key pair can be generated by executing the `start` script

```bash
npm run start
```

The YAML form of the public key will be printed to the console. To configure static keys, add this to the `client_auth->jwks->keys` section of the selected demo's `powersync/service.yaml` (for example, [`demos/nodejs/powersync/service.yaml`](../demos/nodejs/powersync/service.yaml)).

The `DEMO_JWKS_PUBLIC_KEY` and `DEMO_JWKS_PRIVATE_KEY` values will be printed to the console.
For the Node.js and Django demos, add these values to that demo's `.env` file (for example, [`demos/nodejs/.env`](../demos/nodejs/.env)). Their backends use these keys to sign tokens and serve a JWKS endpoint.
